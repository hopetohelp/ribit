# ריבית

מחשבון ריבית דריבית לאנדרואיד שעובד באופליין. אפשר לחשב סכום התחלתי והפקדות קבועות,
להשוות שני מסלולים, ולשמור את ההשוואה או החישוב לשימוש חוזר במכשיר.

## שימוש

- **מחשבון** — סכום התחלתי, הפקדה חודשית או שנתית לפי בחירה, ריבית שנתית אפקטיבית
  ותקופה של חודש עד 100 שנה. אפשר לבחור מתי להפקיד ולהציג את הסכומים ב־₪, דולר,
  אירו או לירה שטרלינג. המטבע ומועד ההפקדה נמצאים תחת **אפשרויות מתקדמות**.
  המטבע משמש לתצוגה.
- **השוואה** — לכל מסלול הגדרות משלו. הפער מחושב במועד הסיום של המסלול הקצר.
  יתרת הסיום של כל מסלול מוצגת לפי משכו.
- **שמורים** — פתיחה, עריכה, שמירה כעותק או מחיקה. נתוני הקלט והתחזית נשמרים
  במכשיר ב־Room.

הממשק בעברית מימין לשמאל ותומך במקלדת חיצונית ובחיצי ניווט. ניתן לדפדף בין
רכיבים עם Tab ו־Shift+Tab, ולבחור עם Enter. דרישת המינימום היא Android 6.0
‏(API 23).

## איך מחושבת היתרה

שיעור הצמיחה החודשי הוא `(1 + annualRate)^(1 / 12) - 1`, כאשר שיעור הריבית השנתי
מבוטא כשבר עשרוני. הפקדה בתחילת תקופה נכנסת לפני הריבית של החודש הראשון בה.
הפקדה בסופה נכנסת אחרי הריבית של החודש האחרון בה. בהפקדות שנתיות, תקופה
מתחילה בתחילת חודש 1, 13, 25 וכן הלאה, ומסתיימת בסוף חודש 12, 24, 36 וכן הלאה.

התחזית מבוססת על שיעור קבוע לאורך כל התקופה. הסכומים מעוגלים לשתי ספרות
בתצוגה, והחישוב הבסיסי הוא לפני דמי ניהול, מס ואינפלציה.

## בנייה והתקנה

נדרשים JDK 21 ו־Android SDK Platform 36. ההרצה הראשונה של Gradle מורידה את
תלויות הבנייה. האפליקציה עצמה פועלת ללא הרשאת אינטרנט.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

אפשר גם לפתוח את הריפו ב־Android Studio ולבנות או להריץ את מודול `app`.
