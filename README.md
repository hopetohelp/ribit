# ריבית

מחשבון ריבית דריבית בעברית עם הפקדות קבועות, השוואת שני מסלולים ושמירה מקומית.
אותם מסכים ומנוע חישוב משמשים את Android ואת האתר.

[פתיחת האתר](https://ribit.hopetohelp.net) · [הורדה ל־Android](https://ribit.hopetohelp.net/android)

## שימוש

- **מחשבון** — סכום התחלתי, הפקדה חודשית או שנתית, תשואה שנתית ותקופה.
- **מתקדם** — מטבע, תזמון הפקדות, דמי ניהול, אינפלציה ומס במימוש. ההסברים מופיעים בסוף התפריט.
- **השוואה** — מסלול ב׳ מקבל את ערכי מסלול א׳ עד לעריכה עצמאית. אפשר לבחור לכל מסלול חישוב שמור באותו מטבע. הפירוט מציג ערך זהה פעם אחת במרכז השורה, וערכים שונים בשני טורים.
- **גרף** — לחיצה או בחירה במקשים מציגה תאריך, קרן מצטברת ותשואה נטו. תאריכי התחזית מתחילים במועד החישוב. בחישוב ישן ללא תאריך התחלה, משמש תאריך השמירה.
- **שמורים** — פתיחה, עריכה, שמירת עותק ומחיקה. Android שומר ב־Room ופותח גם חישובים מגרסה 1. האתר שומר בדפדפן באמצעות IndexedDB.
- **תפריט** — מראה בהיר או כהה ופרטי קשר.

האתר זמין ב־[ribit.hopetohelp.net](https://ribit.hopetohelp.net).
במסך הפתיחה של ״הפלא השמיני״, ״כניסה לאתר״ פותחת את בחירת התצוגה. ״מסך מלא״ פותח את המחשבון בחלון הדפדפן, ו״כאפליקציה״ פותח את בחירת המכשיר והגודל. המונה בכפתור מציג את מספר הצופים באתר.
ב־Qin 1S+ הניווט מתבצע במקשים בלבד. מעלה ומטה עוברים שורה אחת. ימינה ושמאלה עוברים לשדה הסמוך, או לשורה הבאה או הקודמת בקצה. המסך מזיז את התוכן רק כדי לחשוף את הפריט שבמיקוד.
ב־Qin F21 Pro אפשר לגעת במסך או להשתמש באותם מקשי הניווט וההקלדה.
המקש העגול מאשר, והמקש הימני עם סמל השפופרת חוזר למסך הקודם. במכשירי המגע כפתורי הצד
ו־Page Up / Page Down גוללים בכל מסך. כפתור החזרה בפס העליון משותף לאתר ולאפליקציה.
בשני דגמי Qin לחיצה קצרה על אחד המקשים העליונים עוברת ללשונית הסמוכה באותו כיוון. לחיצה ממושכת בשמאל פותחת את התפריט, ובימין מוחקת תו.
בשמירת שם ב־Qin לחיצות חוזרות באותו מקש מחליפות אות, # מחליף בין עברית למספרים ו־* מוסיף רווח.
מונה ״צופים באתר״ מתחיל ב־30, שומר מזהה אקראי באחסון המקומי וסופר כל מזהה פעם אחת. מונה ההורדות מתחיל ב־15
כהערכה להורדות הקודמות מ־GitHub ומוסיף בקשות חדשות להגשת ה־APK דרך האתר.

## הנחות החישוב

התשואה ודמי הצבירה מוזנים כשיעורים שנתיים אפקטיביים ומומרים למקדמים חודשיים.
דמי הפקדה מנוכים בעת כל הפקדה, כולל הסכום ההתחלתי. בתחילת חודש נכנסות ההפקדות
שתוזמנו לתחילתו. אחרי התשואה החודשית מנוכים דמי הצבירה ואז נכנסות הפקדות סוף חודש.

המס המשוער חל על רווח חיובי בעת מימוש מלא, לפי סוג ושיעור שהוזנו.
במס נומינלי משתמשים בבסיס העלות המקורי. במס ריאלי כל הפקדה מוצמדת
ממועד ההפקדה ועד המימוש, עם רצפה בגובה בסיס העלות המקורי במקרה של ירידת מדד.
אפשר לכלול את דמי ההפקדה בבסיס העלות. היתרה נטו מחולקת במדד המצטבר כדי להציגה
בכוח הקנייה של היום. כל נקודה בגרף היא תרחיש מימוש במועד שלה.

## צ׳אט באתר

״נשמח לשמוע אתכם״ פותח את מסך הצ׳אט באתר. משתמש מחובר יכול לשלוח הודעות למנהל האתר ולהמשיך את השיחה במכשיר אחר. לפני התחברות או כשאין חיבור לענן, הטיוטות נשמרות בדפדפן הנוכחי. אפשר להעתיק טיוטה לשדה ההודעה ולשלוח אותה לאחר התחברות וחידוש החיבור.
מסך המנהל נמצא ב־`/admin-chat`. ההגדרה הראשונה נעשית עם קוד חד־פעמי שהגיבוב שלו נשמר ב־`CHAT_SETUP_HASH` ב־Cloudflare.

## חשבון ושמירה בענן

באתר אפשר ליצור חשבון עם מייל וסיסמה או להמשיך עם Google. חיבור Google לחשבון קיים עם אותה כתובת מייל דורש את סיסמת החשבון פעם אחת. בצ׳אט של משתמש מחובר מוצג החלק שלפני @ ככינוי.
כשנכנסים לחשבון, לחיצה על ״שמירה״ שומרת את החישוב או ההשוואה בענן. השמורים זמינים אחרי כניסה באותו חשבון בדפדפן אחר.
עמוד החשבון מציג את שלושת הפריטים בענן שנפתחו לאחרונה ואת מצב החיבור ל־Google. מסך ״שמורים״ מציג את פריטי החשבון ואת הפריטים בדפדפן לפי תאריך. בהגדרות אפשר לסנכרן עותקים מהמכשיר לענן ידנית או אוטומטית. הסנכרון האוטומטי מופעל לפי בחירה עבור החשבון בדפדפן הזה.
בשלב זה המייל הוא מזהה לכניסה, ללא אימות מייל או שחזור סיסמה.
הגדרות השרת כוללות סוד `RIBIT_ACCOUNT_KEY` קבוע המשמש לבידוד חשבונות ולגיבוב סיסמאות.

## גיבוי והעברה

מתוצאת חישוב או השוואה אפשר לייצא קובץ JSON גם לפני שמירה. במסך ״שמורים״ אפשר לחפש, לסנן לפי סוג ומקור, ולשתף כל פריט כקובץ או כקישור. קישור שיתוף מכיל את פרטי הפריט וכל מי שקיבל אותו יכול לפתוח עותק. בהגדרות אפשר לייצא את כל הפריטים ולייבא גיבוי לאחר תצוגה של מספר הפריטים.
הייבוא מוסיף עותקים לרשימה ושומר על הפריטים הקיימים. הקבצים כוללים את נתוני החישובים וניתנים להעברה בין מכשירים.
מונה Safari סופר פתיחות ראשונות של יישום אינטרנט מותקן. מוני Android ו־Windows סופרים בקשות הורדה.

## Windows

מתקין `Ribit-Setup-<version>.exe` מיועד ל־Windows במחשבי x64 ומכיל את כל קובצי האפליקציה והגופנים.
האתר מגיש את המתקין דרך `/download/windows`, ומקור הקובץ הוא GitHub Releases. אפשר להעתיק אותו למחשב מנותק ולהתקין עבור המשתמש הנוכחי. החישובים נשמרים ב־IndexedDB בפרופיל ריבית.
התוכנה החתומה בודקת עדכונים בפתיחה, בחזרה לרשת ובתפריט. כשעדכון מוכן, הוא מותקן בסגירה או בלחיצה על ״הפעלה מחדש לעדכון״.
הגרסה המותקנת מוצגת ב״אודות״ ובחלון העדכונים. משתמשים בגרסה 0.2.2 ומטה מורידים פעם אחת את המתקין החדש ומפעילים אותו כשהתוכנה עדיין מותקנת במחשב.

```sh
cd desktop
npm ci
node --test updates.test.cjs
npm run build:windows
```

קובצי ההפצה נוצרים ב־`desktop/dist/`. הגרסה נקבעת ב־`desktop/package.json`. לפרסום, דוחפים תג `windows-v<version>` שתואם לגרסה.
תהליך GitHub Actions בונה מתקין חתום, בודק התקנה והפעלה, מפרסם את המתקין עם `latest.yml` וקובץ ה־blockmap, ומעדכן את רשומת `windows-latest` במרחב `DOWNLOADS`.
בתצורה הראשונית מגדירים את הסודות `WINDOWS_CSC_LINK`, `WINDOWS_CSC_KEY_PASSWORD` ו־`CLOUDFLARE_KV_API_TOKEN`, ואת המשתנים `CLOUDFLARE_ACCOUNT_ID` ו־`RIBIT_DOWNLOADS_NAMESPACE_ID`. משתמשים בתעודת חתימת קוד שהמחשבים נותנים בה אמון ושומרים על אותה זהות מפרסם גם בעדכונים הבאים.

אפשר להריץ את תהליך ההפצה ידנית מ־GitHub Actions עם תג קיים ולהשאיר את `activate_catalog` כבוי. לאחר אימות שהמתקין החתום, `latest.yml` וה־blockmap זמינים בגרסה הציבורית, מפעילים אותה ב־Cloudflare על ידי כתיבת מספר הגרסה ל־`windows-latest` במרחב `DOWNLOADS`.

מספר הגרסה של האתר נקבע ב־`web/version.txt` ומוצג בתחתית חלון הפתיחה ובחלון ״אודות״ של המחשבון באתר.

## בנייה

סקילי Kotlin, בדיקות Android ו־Compose זמינים ב־[.agents/skills](.agents/skills/README.md).

Android דורש JDK 21 ו־SDK Platform 36. גרסת Android מינימלית היא 6.0‏ (API 23).
האפליקציה כוללת את קובצי הממשק והגופנים ופועלת באופליין.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

בניית האתר ובדיקות מנוע החישוב דורשות Node.js 22 ומעלה.

בסביבת ענן נקייה על Linux x86_64, אפשר להכין את כלי הבנייה של ריבית ולהריץ פקודות עם הגדרות הסביבה שלהן:

```sh
bash .agents/setup-env.sh
bash .agents/setup-env.sh ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
bash .agents/setup-env.sh node --test web/finance.test.cjs web/preview-bundle.test.cjs
bash .agents/setup-env.sh node web/build.mjs
```

הסקריפט משתמש ב־JDK 21, ב־Node.js 22 ומעלה וב־Android SDK שמוגדרים כבר בסביבה.
בסביבה נקייה, כלים שהסקריפט מוריד נשמרים ב־`.agents/.toolchain/`.
את פקודות הבנייה אפשר להפעיל דרכו כדי להחיל על התהליך את נתיבי הכלים, הפרוקסי והתעודות.

```sh
node --test web/finance.test.cjs web/preview-bundle.test.cjs
node web/build.mjs
python3 -m http.server 3265 --directory web/dist
```

התצוגות המקדימות מיועדות להדגמה ולבדיקה מקומית. אם הדפדפן חוסם אחסון קבוע, התצוגה מודיעה שהשמירה תקפה עד לסגירה.

```sh
node web/preview-bundle.mjs            # יוצר את web/preview/preview.html (עם מסגרת מכשיר)
node web/preview-bundle.mjs --app-only # יוצר את web/preview/app-preview.html (אפליקציה ישירה ללא iframe)
```

ליצירת מודול Worker שאפשר להעלות ל־Cloudflare, הפקודה `node web/build.mjs /path/to/worker.mjs`
מארזת את אותם קבצים. לאחר פרסום ה־Worker, מחברים אליו את `ribit.hopetohelp.net`
כ־Custom Domain בחשבון של האזור `hopetohelp.net`. מחברים את מרחב ה־KV הקיים של ההורדות בשם `DOWNLOADS`.

## חנות Android עצמאית

הקישור `/android` פותח את מגירת ההורדה במסך הפתיחה. המגירה מורידה את ה־APK דרך `/download`. האפליקציה בודקת אם יש עדכון בפתיחה, בחזרה לרשת ודרך ״בדיקת עדכון״ בתפריט. הגרסה המותקנת מוצגת ב״אודות״ ובחלון העדכונים. התקנה ועדכון מתבצעים באישור המשתמש דרך מתקין המערכת. במצב אופליין אפשר להמשיך להשתמש במחשבון ובחישובים המקומיים.

לפרסום גרסה חדשה, הגדילו את `versionCode` ואת `versionName` ב־`app/build.gradle.kts`, בנו APK מסוג release וחתמו עם מפתח ההפצה הקיים. בדקו שדרוג מעל הגרסה הקודמת עם חישובים שמורים. לאחר שה־Worker עם החנות פעיל, התחברו ל־Wrangler בחשבון שמנהל את `DOWNLOADS` והפעילו:

```sh
node web/publish-android.mjs /path/to/ribit-signed.apk --publish DOWNLOADS_NAMESPACE_ID
```

הפקודה בודקת את שם החבילה, תעודת החתימה ומספר הגרסה לפני העלאה. פרטי הקטלוג וקובץ ההתקנה נכתבים יחד לאותה רשומה ב־KV. בהרצה ללא `--publish` הקובץ נבדק מקומית. עד שמפרסמים גרסה חדשה, החנות מגישה את ה־APK הקיים בשם `ribit-0.2.1.apk`. אחרי העלאה, ייתכן שיחלפו כשישים שניות עד שהגרסה החדשה תופיע בכל האזורים.
