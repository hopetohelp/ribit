# Android development skills

Ribit uses Kotlin, Room, JUnit and a WebView that renders the shared web UI. The Kotlin, Gradle, JUnit, coroutine testing and ADB skills apply to the current project. The Compose skills apply when reviewing or developing Compose code.

The Android skills below include their upstream licenses. The copies retain upstream instructions and their runtime references.
